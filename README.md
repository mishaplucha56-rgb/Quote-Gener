# 💬 Random Quote Generator

Stil'noe desktopnoe prilozhenie na **Python** i **CustomTkinter** dlya generacii sluchaynykh vdokhnovlyayushchikh citat.

---

## ✨ Osobennosti (Features)

- 🎲 **Sluchaynyy vybor:** Vyvod novoy citaty i avtora po odnomu kliku.
- 🎨 **Modern UI:** Krasivyy temnyy interfeys na CustomTkinter.
- 📋 **Kopirovanie v bufer:** Knoopka dlya bystrogo kopirovaniya teksta citaty.
- 🌐 **Online API / Baza dannykh:** Zagruzka citat iz vneshneti ili iz lokal'nogo JSON-fayla.

---

## 🛠 Tekhnologii

- **Python 3.x**
- **CustomTkinter** (GUI)
- **requests** (esli citaty berutsya iz API)
- **Pillow / PIL** (rabota s ikonkami)
